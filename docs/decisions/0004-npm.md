# 0004: npm as the frontend package manager

- Status: Accepted
- Date: 2026-11-19

## Context

`src/web` needs one package manager used the same way locally and in CI.

## Decision

Use **npm** with a committed `package-lock.json`. CI installs with `npm ci`, which fails
if the lockfile and `package.json` disagree.

## Alternatives considered

| Option | Trade-off |
| --- | --- |
| pnpm | Faster installs and a strict dependency tree that catches undeclared imports; needs an extra install step everywhere. |
| Yarn | No clear gain over npm for a single app. |

## Consequences

- Zero extra tooling for contributors and CI (`actions/setup-node` with npm cache).
- Hoisted `node_modules` can hide an undeclared dependency; ESLint's import rules and
  review catch most of these.
